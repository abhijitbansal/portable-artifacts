# make-demo phase 1 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Give the skill a URL and some use cases and get a click plan page you can approve, where every step is labelled `look`, `change` or `danger`, and nothing has been clicked.

**Architecture:** `scout.mjs` opens pages read-only and writes a digest. A pure classifier labels every control. `build.mjs` joins `demo.json` with the digest offline, refuses steps it cannot resolve, and has make-explainer draw the plan page. `session.mjs` stores a hand sign-in outside the project. Nothing in phase 1 clicks, types or submits.

**Tech Stack:** Node 20+, Playwright 1.64.0, ajv 8.20.0 (already pinned), make-explainer plan pages. No new dependency.

**Spec:** `docs/superpowers/specs/2026-11-24-make-demo-design.md` sections 6.1 to 6.4, 6.6, 6.10; `docs/superpowers/plans/2026-11-24-make-demo-handoff-p1.md`

## The claim of this phase

1. Scout never clicks, types, submits, or follows a link it does not class as `look`.
2. Every step on the plan page is bound by one hash, names one control scout saw, and carries its effect. Unknown is `change`. A step that types into a password field is refused.
3. With a session: no value, body text or picture reaches a printed line, `scout.json` or the plan page. Control names, headings and layout do, with emails, long numbers and keys masked. No cookie or token is ever printed.

A finding outside this claim that is not an obvious failure goes to "Known limits".

### Task 1: Effect classes and masking

**Files:** create `scripts/lib/effects.mjs`, `scripts/lib/mask.mjs`; test `test/effects.test.mjs`, `test/mask.test.mjs`.

**Produces:**
- A **control**: `{ role, name, kind, href, newTab, download, submits, formAction, formMethod, scripted }`. `kind` is `link` (an `<a href>` with an http(s) address that is not `#`), `button`, `disclosure` (role tab, `summary`, or `aria-expanded`/`aria-haspopup`), `field`, `password`, `select`, `toggle`, `other`. `href` and `formAction` are absolute or null. `scripted` is true with an inline `onclick`, `data-method`, `data-turbo-method` or `hx-post|put|patch|delete`.
- `classify({ do: string, control: object|null, value?: string, pageUrl: string, origins: string[], lang: string|null }): { effect: 'look'|'change'|'danger', reason: string }`
- `dangerWord(text: string): string|null`
- `isFollowable(control, { pageUrl, origins, lang }): boolean`: the click is `look`, the kind is `link`, and it is another document on the page's own origin.
- `maskText(text: string): string` and `maskPath(pathname: string): string`.

**Rules, first match wins:**
1. `hover`, `scroll`, `wait`, `show`: `look`.
2. For `click`, `press` and `goto`: `dangerWord` in the control's name, `href` (path, query, hash), `formAction`, or a `goto` address: `danger`.
3. `goto` in `origins`: `look`. (Outside `origins` it is a spec error, Task 2.)
4. `type`, `select`, `press`: `change`.
5. `click` on a `link`: `look` only when its origin is in `origins`, not `download`, not `newTab`, not `scripted`, and `lang` starts with `en`; else `change`.
6. `click` on a `disclosure` with no `href`, not `submits`, not `scripted`: `look`.
7. Anything else: `change`.

Danger words, matched whole after splitting camelCase, `-`, `_`, `/`, `.`, `=`, `&` and lower-casing: delete, remove, destroy, erase, trash, archive, reset, revoke, deactivate, disable, pay, payment, buy, purchase, checkout, "place order", subscribe, unsubscribe, subscription, upgrade, donate, refund, transfer, withdraw, send, invite, publish, unpublish, deploy, merge, "sign out", signout, "log out", logout, "log off", logoff, account, billing.

## How it is built

Six builder dispatches at most, one per task, in order, Sonnet at high effort: each needs the interface of the one before, and the browser is a serial resource. The main session reviews each diff, runs the suites, commits and pushes. Then one reviewer. No other agents.

## Known limits, to be stated

- English words only for `danger`; a site without `lang="en"` gets `change` on every link.
- A plain link in English with a harmless name and address that still changes something on GET is `look`.
- A `look` disclosure may send a request; phase 2 pauses on it.
- A redirect is followed before it can be refused: the GET to the other site has gone out. The digest is refused and the report says so.
